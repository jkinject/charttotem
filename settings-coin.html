개인정보처리방침

차트토템은 책상 위에서 시세와 시각을 보여 주는 기기예요. 기기와 이 설정 페이지는 개인정보를 수집하지 않아요. 앱에서 어디서든 설정할 수 있도록 기기는 아래 "클라우드로 보내는 것"만 중계 서버(Cloudflare)에 올려요.

클라우드로 보내는 것

  • 기기 ID, 펌웨어 버전, 등록한 종목과 시세, 화면 설정, 기기 이름, 연결된 Wi-Fi 이름
  • Wi-Fi 비밀번호는 보내지 않아요. 중계 서버는 마지막 상태와 전달 대기 중인 설정만 보관하고, 계정이나 연락처 같은 개인정보는 없어요.

기기에 저장되는 것

  • 등록한 종목, 화면 레이아웃·표시 설정, 밝기, 시간대, 기기 이름
  • 연결한 Wi-Fi 이름과 비밀번호 (기기 플래시 메모리에만 저장돼요)

「초기 설정으로」를 누르면 Wi-Fi 정보가 지워지고, 기기를 처음 상태로 되돌리려면 설정 페이지에서 종목과 이름을 지우면 돼요.

기기가 접속하는 곳

  • 시세: 주식 변형은 네이버 증권, 코인 변형은 Binance 의 공개 시세 API. 요청에는 종목 코드만 들어가요.
  • 시각: NTP 서버(pool.ntp.org, time.nist.gov)
  • 그 외 분석·광고·원격 수집 서버에 접속하지 않아요.

이 설정 페이지

  • 기기 안에서 직접 제공되고 같은 Wi-Fi 안에서만 열려요. 쿠키·분석 도구·외부 스크립트가 없어요.
  • 브라우저 저장소에는 「홈 화면 추가 안내를 닫았는지」만 남겨요.

런처 앱 (jkinject.github.io/charttotem)

  • 등록한 기기 목록(주소·ID·이름)을 사용자의 브라우저 저장소(localStorage)에만 보관하고 서버로 보내지 않아요.
  • GitHub Pages 가 정적 파일을 제공하며, GitHub 의 서버 접속 기록 처리 방식은 GitHub 의 개인정보처리방침을 따라요.

문의

궁금한 점은 런처 앱의 저장소(GitHub jkinject/charttotem)로 알려 주세요.
