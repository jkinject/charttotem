11자주 묻는 질문

자주 묻는 질문

어느 거래소 코인을 넣을 수 있나요?

업비트·빗썸·코인원·바이낸스의 코인을 이름이나 심볼로 검색해 거래소를 섞어서 최대 5개까지 등록합니다.

거래소 계정을 연결해야 하나요?

아니요. 로그인이나 API 키 없이 거래소의 공개 시세만 받아옵니다. 잔고나 주문 기능은 없습니다.

시세는 얼마나 자주 바뀌나요?

거래소 공개 시세를 10초 간격으로 받아옵니다. 5코인이면 돌아가며 조회합니다.

밤이나 주말에도 시세가 바뀌나요?

네. 코인은 24시간 거래되므로 밤에도 주말에도 갱신되고, 시계도 그대로 동작합니다.

밤에 화면이 밝지 않나요?

밤 12시부터 아침 6시까지는 자동으로 어두워집니다. 시작·끝 시간은 설정 앱의 야간 모드에서 바꿀 수 있습니다.

앱을 따로 설치해야 하나요?

설치 없이 폰 브라우저에서 엽니다. 기기 화면의 QR을 찍거나 ID 6자리와 연결 코드를 넣으면 되고, 집 밖에서도 설정할 수 있습니다.

Wi-Fi는 어떤 걸 지원하나요?

2.4GHz만 지원합니다. 이름 끝에 5G가 붙은 Wi-Fi는 연결되지 않습니다.

충전기도 들어 있나요?

본체와 USB-C 케이블이 들어 있고 충전기는 포함되지 않습니다. 5V USB 충전기나 PC·모니터의 USB 포트에 꽂아 쓰면 됩니다.

주식 시세도 볼 수 있나요?

「코인만」 구성은 코인 전용입니다. 주식·ETF는 주식시계를, 주식과 코인을 함께 보려면 「올인원」 구성을 고르세요.

  • Wi-Fi 2.4GHz가 필요합니다. 5GHz 전용 공유기에는 연결되지 않습니다.
