아직 등록된 기기가 없어요
기기 화면의 QR을 폰 카메라로 찍으면 여기에 자동으로 추가돼요.
처음 설정(Wi-Fi 연결)을 아직 안 했다면 기기 화면의 Wi-Fi QR부터 찍어 주세요.
기기 추가
기기가 안 열릴 때
  1. 폰 Wi-Fi가 기기와 같은 Wi-Fi인지 확인하세요. 기기가 쓰는 Wi-Fi 이름은 위 기기 항목에 적혀 있어요. (5GHz가 아닌 2.4GHz 이름)
  2. 기기 화면이 켜져 있는지, 가격이 움직이는지 보세요.
  3. 기기 전원을 뽑았다가 10초 뒤 다시 꽂으세요. 켜질 때 화면에 주소가 잠깐 떠요.
  4. 기기 화면에 QR이 떠 있으면 폰 카메라로 다시 찍으세요. 가장 확실한 방법이에요. 주소가 바뀌어도 자동으로 맞춰져요.
  5. QR이 없으면 같은 Wi-Fi에서 기기 찾기를 눌러 보세요. 기기 화면에 주소가 보이면 기기 추가에 직접 입력해도 돼요.
  6. 기기 화면에 Wi-Fi 설정 QR(1/2)이 떠 있으면 Wi-Fi 정보가 지워진 거예요. 그 QR을 찍어 처음 설정을 다시 하세요.
