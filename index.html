같은 Wi-Fi 에서 기기 IP 로 바로 여는 개발용 경로예요. 고객용은 위의 「기기 연결」(클라우드) 이에요.

기기 연결

1단계 · 기기 ID

기기 화면 아래쪽에 적힌 Device ID 6자리를 입력하세요. 기기 화면의 QR 을 찍었다면 자동으로 채워져요.

기기가 켜져 있고 Wi-Fi 에 연결돼 있어야 해요. ID 가 안 보이면 기기 전원을 뽑았다 꽂으면 켜질 때 화면에 떠요.

2단계 · 기기 화면의 숫자

기기 화면에 숫자 6자리가 뜨길 기다리는 중이에요... (최대 30초)

기기 화면에 뜬 숫자 6자리를 그대로 입력하세요. 기기 옆에 있는 사람만 연결할 수 있게 하는 확인 절차예요.
