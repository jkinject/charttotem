# 차트토템 런처 (PWA)

책상에 세워두는 투자자의 작은 토템, **차트토템** 기기를 폰에서 관리하는 설치형 웹앱.
GitHub Pages 로 호스팅: https://jkinject.github.io/charttotem/

- 기기 목록(여러 대), 온보딩/기기 QR 로 자동 등록 (`?add=1&id=&ip=&host=&ssid=`)
- 가격·연결 상태 확인, 종목 변경(낙관적 업데이트) — Chrome(안드로이드) 의 Local Network Access 로 HTTPS 페이지에서 기기(HTTP) 와 통신
- 주식(kstock) 기기는 **종목명 검색**으로 바꾼다 (펌웨어 1.4.0-kstock 이상): 입력창에 「삼성전자」「테슬라」처럼 치면 300ms 뒤 기기의
  `GET /api/search?q=` (네이버 자동완성 프록시, 코스피·코스닥 + 미국 등 해외) 결과가 목록으로 뜬다 — 종목명 강조, 코드·거래소 배지, 현재가·등락률
  (상승 빨강 / 하락 파랑). 해외 행 가격은 `GET /api/quote?code=` 로 한 행씩 순서대로 채운다. 행을 누르면 `POST /api/settings?code=` 로 적용하고
  `/api/state` 를 보며 확인한다. Enter 는 첫 행 선택(결과가 없으면 입력값을 코드/티커로 그대로 적용). 기본 종목 칩은 없다(0.3.1부터).
  - 종목 식별자 규칙은 펌웨어 `marketSanitizeSymbol` 과 같다: 숫자로 시작하는 6자리 영숫자는 국내 종목코드(대문자), 그 외 영문/숫자/`.`/`-` 1~12자는
    해외 로이터코드(`TSLA.O`, `KO`, `BRKb`, `6758.T` — 대소문자 유지).
  - 가격 표기는 `/api/state` 의 `currency` 를 따른다: KRW 는 정수 + 원, USD 는 `$` + 소수 2자리(10,000 이상이면 정수), 그 외는 숫자 + 통화 코드.
- 코인 기기는 심볼 입력(예: `ARB`) + 「변경」 버튼 + 추천 칩. **주식 기기에는 기본 종목 칩이 없다** — 검색으로만 추가한다 (0.3.1).
- **종목 여러 개 (펌웨어 1.5.0 이상)**: 기기 카드에 등록된 종목 목록(최대 5개, 국내·해외·코인 섞어도 됨)이 보이고, 기기 화면에 지금 보이는 종목은
  「표시 중」으로 표시된다. 검색 결과·칩은 목록에 **추가**(`POST /api/settings?code=` 는 `add=` 의 별칭)하고, 행의 ✕ 는 `remove=` 로 뺀다
  (마지막 하나는 못 뺌). 「화면 전환」 선택(끄기/3/5/10/15/30/60초)은 `rotate=` 로 저장되어 기기 화면이 그 간격으로 다음 종목으로 넘어간다.
  이미 있는 종목을 다시 고르면 기기 화면을 그 종목으로 돌린다. 옛 펌웨어(`/api/state` 에 `codes` 가 없음)에서는 종목 하나를 바꾸는 예전 동작 그대로.
- **화면 레이아웃 · 테마 (펌웨어 2.0.0 이상)**: 기기 카드의 「화면 · <레이아웃>」 버튼을 누르면 패널이 열린다. 테마 탭(주식/시계) → 레이아웃 목록은 기기의
  `GET /api/layouts` 에서 받고(이름 + 짧은 설명 + 「종목 전환」/「전체 표시」), 누르면 `POST /api/settings?layout=<ID>` (예 `S01` HERO, `C03` HORIZON).
  주식 테마는 시세가 전면에, 시계 테마(ORBIT·FIVE DOTS·HORIZON·CLOCK FACE·STACK·CALENDAR·TIDE·NIGHT, 펌웨어 2.1.0)는 탁상시계처럼 보이고 종목은 작게. CLASSIC(`S00`)이 v1.x 화면.
  - 「상승 · 하락 색」: 한국식(빨강 ↑ 파랑 ↓) / 글로벌(초록 ↑ 빨강 ↓) → `colors=kr|global`. 기기 화면의 모든 등락 색에 적용된다 (런처 카드 색은 기기 종류 기준 그대로).
  - 「시간대」: 프리셋(서울·도쿄·홍콩·런던·뉴욕·LA 등 POSIX TZ) + 직접 입력 → `tz=`. 시계 테마의 시각(SNTP)과 `/api/state` 의 `time/date` 가 이 시간대를 따른다.
  - 옛 펌웨어(`/api/state` 에 `layout` 이 없음)에서는 버튼이 보이지 않는다.
- 같은 Wi-Fi 대역 스캔으로 기기 찾기, 주소 직접 입력
- 오프라인에서도 열리는 문제 해결 가이드, 홈 화면 설치 안내
- **디자인 (0.4.0)**: 펌웨어 설정 페이지와 같은 디자인 시스템(`firmware/docs/settings-redesign/design-system.md`) — 카드 없는 플랫 리스트, 왼쪽 정렬 헤더, 행 + 머리카락 선 + 8px 띠, Lucide 24px 라인 아이콘(`index.html` 인라인 스프라이트 = `firmware/tools/web/icons.svg`, `app.js` 의 `I("name")`).
  `style.css` 앞부분은 펌웨어 `tools/web/settings.css` 와 동일하고 끝의 "런처 전용" 블록만 다르다. 펌웨어 쪽 CSS 를 바꾸면 여기도 맞춘다.
- 기기 항목 = 프로필(이름·Wi-Fi·주소·⋯ 메뉴) → 현재 종목 가격 → 종목 목록 → 화면 전환 → 검색/추가 → 「화면 · 레이아웃」 패널 → 「기기 설정 열기」. 배포 후 설치된 앱은 `sw.js` 의 `CACHE` 이름이 바뀌어야 새 파일을 받는다.
- 빌드 없음. 정적 파일 그대로 배포 (`index.html`, `app.js`, `sw.js`, `style.css`, `manifest.json`, `icons/`)

펌웨어 쪽 연동: 기기의 `src/brand.h` `LAUNCHER_URL` 이 이 주소. 도메인을 바꾸면 거기도 바꿔서 OTA.
`sw.js` 의 `CACHE` 이름을 올리면 설치된 앱이 새 파일을 받는다.
