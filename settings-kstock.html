    개인정보처리방침

    차트토템은 책상 위에서 시세와 시각을 보여 주는 기기예요. 계정·이름·연락처 같은 개인정보는 받지 않아요. 앱에서 어디서든 설정할 수 있도록 기기는 자기 상태를 중계 서버(Cloudflare Workers)에 올리고, 앱은 그 서버를 통해서만 기기와 대화해요. 아래에 무엇이 어디로 가고 어떻게 지우는지 적었어요.

    기기가 중계 서버에 올리는 것

    • 기기 ID, 펌웨어 버전·변형(주식/코인), 기기 이름, 등록한 종목과 지금 시세, 화면 레이아웃·표시 설정, 밝기, 시간대
    • 연결된 Wi-Fi 이름, 기기에 저장된 Wi-Fi 이름 목록, 「Wi-Fi 추가」에서 주변을 훑었을 때 보인 Wi-Fi 이름 목록, 공유기 안 사설 IP 주소
    • 진단값(남은 메모리, 켜진 시간, 마지막 재시작 사유, 동기화 소요 시간)

    서버는 기기마다 마지막 상태 하나만 덮어쓰며 보관하고, 과거 기록은 남기지 않아요. 기기 ↔ 서버 구간은 기기 사양 때문에 암호화되지 않은 HTTP 를 쓰고, 대신 기기만 아는 비밀키 서명으로 위변조를 막아요. 앱 ↔ 서버 구간은 HTTPS 예요.

    앱에서 설정할 때 서버를 거치는 것

    • 바꾼 설정(종목·화면·이름 등)은 서버 대기열에 잠시 머물다 기기가 받아 가면 지워져요(최대 50개).
    • Wi-Fi 비밀번호는 「Wi-Fi 추가 · 변경」에서만 보내요. 앱이 HTTPS 로 서버에 보내면 서버는 기기 전용 키로 암호화해 대기열에 넣고, 평문은 저장하지 않아요. 기기가 받아 가면 대기열에서도 지워져요.
    • 종목 검색어와 시세 조회는 서버가 네이버 증권에 대신 물어봐요(주식 변형). 검색어는 저장하지 않아요.

    앱 연결(페어링)

    • 기기 화면의 6자리 코드로 앱을 연결하면 서버가 연결 토큰을 만들어 기기별로 보관해요(기기당 최대 20개). 토큰마다 만든 시각, 마지막 사용 시각, 연결한 브라우저 종류(브라우저가 보내는 User-Agent 앞 60자)를 함께 둬요. 사람을 식별하는 값은 없어요.
    • 토큰은 연결한 폰의 브라우저 저장소에만 있어요. 앱의 ⋯ 메뉴 「기기 삭제」를 누르면 그 토큰을 서버에서도 폐기해요.

    기기에 저장되는 것

    • 등록한 종목, 화면 레이아웃·표시 설정, 밝기, 시간대, 기기 이름, 중계 서버용 비밀키
    • 저장한 Wi-Fi 이름과 비밀번호 — 비밀번호는 기기 플래시 메모리에만 있고 서버에는 암호화된 채 잠시 머물 뿐 남지 않아요.

    지우기

    • 기기 초기화(시스템 → 기기 초기화): 서버에 있는 이 기기의 기록(상태·대기열·연결 토큰·비밀키)을 모두 지우고, 기기도 종목·설정·Wi-Fi 를 지워 처음 상태로 돌아가요. 연결돼 있던 앱은 모두 끊겨요.
    • 기기 삭제(앱 홈의 ⋯ 메뉴): 이 폰의 연결만 끊어요. 기기와 다른 폰의 연결은 그대로예요.
    • 초기화하지 않은 기기의 기록은 기기가 다시 동기화할 때마다 덮어쓰이며, 따로 지우기 전까지 서버에 남아요.

    기기가 접속하는 곳

    • 시세: 주식 변형은 네이버 증권, 코인 변형은 Binance 의 공개 시세 API. 요청에는 종목 코드만 들어가요.
    • 시각: NTP 서버(pool.ntp.org, time.nist.gov)
    • 중계 서버(charttotem-cloud.jkinject.workers.dev, Cloudflare): 위의 상태 동기화, 설정 받기, 한글 글꼴 파일 다운로드, 펌웨어 업데이트 확인·다운로드(GitHub Release 를 서버가 대신 받아 전해 줘요)
    • 그 외 분석·광고 서버에 접속하지 않아요.

    앱 (charttotem.lalatap.kr)

    • GitHub Pages 가 정적 파일을 제공하고, 설정은 Cloudflare 의 중계 서버와만 통신해요. 쿠키·분석 도구·광고 스크립트가 없어요. 두 회사의 서버 접속 기록 처리는 각자의 개인정보처리방침을 따라요.
    • 브라우저 저장소(localStorage)에는 연결한 기기 목록(기기 ID·연결 토큰·이름·변형·고른 아이콘), 홈 화면 추가 안내를 닫았는지, 오프라인용 앱 파일 캐시만 둬요. 어디에도 보내지 않아요.
    • 코인 변형 설정 페이지는 코인 로고 이미지를 jsDelivr CDN 에서 받아요(요청에는 코인 심볼만 들어가요).
